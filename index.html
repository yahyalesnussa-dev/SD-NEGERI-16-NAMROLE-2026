Install Aplikasi E-Rapor

Pasang di layar utama HP atau komputer Anda

Perangkat Mendukung Pemasangan Langsung!

Klik tombol di samping untuk memasang ikon aplikasi.

Android (Google Chrome)

  1. Ketuk ikon titik tiga (⋮) di pojok kanan atas browser Chrome.
  2. Pilih Tambahkan ke layar utama atau Install aplikasi.
  3. Ketuk Tambahkan — ikon E-Rapor SDN 16 Namrole akan muncul di layar utama.

iPhone / iPad (Safari)

  1. Ketuk ikon Bagikan (Share) di bagian bawah layar Safari.
  2. Gulir ke bawah lalu pilih Tambahkan ke Layar Utama (Add to Home Screen).
  3. Ketuk Tambah di pojok kanan atas.

Laptop / PC (Chrome / Edge)

  1. Klik ikon Install / Layar dengan panah di ujung kanan bilah alamat (address bar).
  2. Atau buka menu browser (⋮) → Simpan dan bagikan → Install halaman sebagai aplikasi.
